# Node.js Notes - Day 92

## What is Node.js?
- JavaScript runtime built on Chrome's V8 engine
- Non-blocking, event-driven architecture
- Great for building scalable server-side applications

## Core Modules
- s - File system operations
- path - File path utilities
- http - Create HTTP servers
- os - Operating system information

## npm
- Node Package Manager
- Used to install and manage project dependencies
- 
pm init to start a new project
- 
pm install <package> to add a dependency
